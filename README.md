# Hearthline Architecture — prototype website

Marketing site and client portal with **no database** — demo data lives in memory and resets on server restart.

## Run locally

```bash
cp .env.example .env
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Client portal:** `client@hearthline.studio` / `ChangeMe-Demo-2026!`

See [docs/SECURITY.md](docs/SECURITY.md) for security notes.
